# ระบบบริหารจัดการงานซ่อมเครื่องซักผ้า

เว็บแอปภาษาไทยสำหรับ **บริษัท หาดใหญ่ซาวด์สตาร์ จำกัด (สำนักงานใหญ่)** ใช้จัดการใบงานซ่อม อะไหล่ที่ใช้ในแต่ละใบงาน สต๊อกอะไหล่ และรายงาน รองรับมือถือ (iPhone/Android), แท็บเล็ต และคอมพิวเตอร์ ไม่มีหน้าเข้าสู่ระบบ

## สถานะปัจจุบัน
หน้าจอทุกหน้าใช้งานและกดได้แล้ว (ใบงานซ่อม, รายละเอียด/พิมพ์ใบงาน, สต๊อกอะไหล่, รายงาน, ตั้งค่า) ตอนนี้ใช้ข้อมูลสาธิตที่เก็บในหน่วยความจำของเบราว์เซอร์ (รีเฟรชแล้วรีเซ็ต) ขั้นต่อไปคือเชื่อมฐานข้อมูลกลาง Supabase ตาม [PLAN.md](PLAN.md)

## เทคโนโลยี
- TanStack Start (React 19, TypeScript), Tailwind CSS 4, shadcn/ui, lucide-react
- ฟอนต์ Sarabun, สีหลัก #B71C1C / #D32F2F
- Hosting: Netlify · ฐานข้อมูล (ขั้นถัดไป): Supabase ผ่าน Netlify Functions

## รันบนเครื่อง
```bash
pnpm install
pnpm dev          # http://localhost:3000
# หรือใช้ Netlify CLI เพื่อจำลองฟีเจอร์ของ Netlify
netlify dev
```

## โครงสร้างสำคัญ
- `src/routes/` — หน้าเว็บ (`index` = ใบงาน, `jobs.new`, `jobs.$jobId`, `stock`, `reports`, `settings`)
- `src/lib/company.ts` — ข้อมูลบริษัทชุดเดียวของระบบ
- `src/lib/store.tsx` — ชั้นข้อมูล (ตอนนี้เป็นข้อมูลสาธิต จะเปลี่ยนเป็น API)
- `src/data/fixtures.ts` — ข้อมูลสาธิต (จะลบเมื่อเชื่อมฐานข้อมูล)
